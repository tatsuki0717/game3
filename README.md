# 七つ屋（ななつや）— 質屋経営シミュレーション

*Papers, Please* 風の「書類・品物照合」と、経営シミュレーションを組み合わせた質屋ゲームです。ブラウザで遊べます。

## 遊び方

```bash
npm install
npm run dev      # 開発サーバ（http://localhost:5173）
npm run build    # 本番ビルド（dist/ に静的ファイルを出力）
npm test         # ユニットテスト
npm run simulate -- 100        # ボットで 100 回プレイしてバランスを確認
npm run art                    # Antigravity CLI（agy）で背景画像を生成（任意）
```

フルスクリーン前提のゲーム画面です（F キーで全画面、Esc でメニュー）。ページはスクロールせず、画面はウィンドウに合わせて拡大縮小されます。設定画面で解像度（自動 / 1280×720〜2560×1440）、拡大表示、文字・UI の大きさ、時間の速さ、効果音、画面効果を変更できます。

### 背景画像の生成（agy）

`tools/agy/prompts.json` のプロンプトを Antigravity CLI に渡して `public/img/` に保存し、`public/img/manifest.json` に登録します。登録された画像は起動時に読み込まれ、無い画像はゲーム内蔵の SVG 背景で表示されます。

```bash
npm run art                 # 未生成の画像だけ作る
npm run art -- --force      # すべて作り直す
npm run art -- title shop   # 指定した画像だけ
AGY_CMD=/path/to/agy npm run art
```

`agy -p` はファイル書き込みなどのツールを承認なしで実行するので、信頼できる作業ディレクトリでのみ実行してください。

- **朝**：新聞（相場ニュース）、通達（新しい規則）、盗品手配書を確認して開店。
- **窓口**：客を呼び、ルーペ・天秤などの道具で品物を調べる。「照合」で 2 つの項目（品物の刻印↔カタログ、身分証の写真↔客の顔、有効期限↔今日の日付、シリアル↔手配書 など）を比べて不一致を見つける。欠陥は「指摘」して値切り、盗品・偽造身分証は「通報」。金額を提示して交渉し、質札を発行するか買い取る。
- **怪しい客**：初日から偽物・盗品・期限切れや他人の身分証を持った客が毎日まぎれている。挙動の描写もヒントになる（ただし無実の客にも出る）。
- **夜**：生活費を払い、在庫を陳列・業者売却し、道具や設備に投資する。
- **借入**：資金が足りなければ、HUD の「借入」から潮見信用金庫（手数料 10%）や鮫島ファイナンス（日利 3% の闇金）で追加の借金ができる。
- 30 日目の夜までに借金 ¥1,000,000 を返せるか。エンディングは 8 種類。

進行は自動でブラウザに保存されます（タイトル画面の「続きから」）。
