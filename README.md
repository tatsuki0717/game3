# 七つ屋（ななつや）— 質屋経営シミュレーション

*Papers, Please* 風の「書類・品物照合」と、経営シミュレーションを組み合わせた質屋ゲームです。ブラウザで遊べます。

## 遊び方

```bash
npm install
npm run dev      # 開発サーバ（http://localhost:5173）
npm run build    # 本番ビルド（dist/ に静的ファイルを出力）
npm test         # ユニットテスト
npm run simulate -- 100        # ボットで 100 回プレイしてバランスを確認
```

- **朝**：新聞（相場ニュース）、通達（新しい規則）、盗品手配書を確認して開店。
- **窓口**：客を呼び、ルーペ・天秤などの道具で品物を調べる。「照合」で 2 つの項目（品物の刻印↔カタログ、身分証の写真↔客の顔、有効期限↔今日の日付、シリアル↔手配書 など）を比べて不一致を見つける。欠陥は「指摘」して値切り、盗品・偽造身分証は「通報」。金額を提示して交渉し、質札を発行するか買い取る。
- **夜**：最初に概況（日報）で今夜やることを確認し、タブを切り替えて生活費を払い、在庫を陳列・業者売却し、道具や設備に投資する。古物業者からの仕入れ、翌日の広告（町内チラシ／品目を絞った高価買取チラシ／店頭セール）、店員の雇用（質札の用件を代行）、信用金庫のつなぎ融資で店を回す。概況には純資産（現金＋貸付＋在庫−借金・借入）、質札一覧には質札ごとの請け出し見込みが出る。
- 30 日目の夜までに借金 ¥1,000,000 を返せるか。エンディングは 8 種類。

- **操作のコツ**：机の上の「品目カタログ（控え）」と品物を照合できる。客の表情と「機嫌」ゲージで交渉の引き際を読む。
- **キーボード**：Enter / Space＝次の客・次へ・開店、1〜6＝道具（夜は 1〜7 でタブ切り替え）、← →＝夜の一覧のページ送り、C＝照合モード、Esc＝選択解除。右上の［音］で効果音を切り替え。

進行は自動でブラウザに保存されます（タイトル画面の「続きから」）。
