# 01. 企画書 —『七つ屋（ななつや）』

> 「質（しち）」＝「七（しち）」。質屋の古い通称「七つ屋」をタイトルにした。

## 1. 一言コンセプト

**「カウンター越しに人生を値踏みする」質屋経営シミュレーション。**
*Papers, Please* の「書類を照合して規則違反を見抜く緊張感」と、経営シミュレーションの「資金・在庫・相場を回す楽しさ」を組み合わせる。

## 2. ゲーム概要

| 項目 | 内容 |
|---|---|
| ジャンル | 査定パズル × 店舗経営シミュレーション × 選択型ドラマ |
| プラットフォーム | PC（ブラウザ / Steam 想定）。後にスマホ横画面 |
| プレイ時間 | 本編 30 日（約 4〜6 時間）＋エンドレスモード |
| 視点 | 1 画面固定のカウンター（上：客と店先 / 下：作業机） |
| 想定プレイヤー | Papers, Please / Return of the Obra Dinn / 各種店舗経営ゲームが好きな層 |

## 3. 世界観

- 舞台：架空の地方港町「潮見（しおみ）市」。工場閉鎖で不況が続く 1990 年代初頭風の世界。
- 主人公：亡くなった祖父の質屋「七つ屋」を継いだ若店主。店には **祖父の借金** と **月末の返済期限** が残っている。
- 町には困窮した住民、盗品をさばきたい窃盗団、目を光らせる刑事、地上げを狙う不動産会社がいる。
- 毎日、新しい条例・警察からの通達・相場ニュースが届き、ルールが少しずつ厳しく・複雑になる。

## 4. コア体験（3 本柱）

1. **見抜く緊張（Papers, Please 要素）**
   身分証・盗品手配書・品物の刻印や重さを照合し、偽物・盗品・規則違反を見抜く。見落とすと罰金や営業停止。
2. **値をつける駆け引き（交渉要素）**
   査定額を自分で決め、客と交渉する。安く買い叩けば儲かるが、評判と良心が削れる。
3. **店を回す手応え（経営要素）**
   貸付金・利息・質流れ品・店頭販売・相場変動を管理し、借金を返して店を守る。

## 5. 1 日の流れ（ゲームループ）

```
[朝] ニュース・通達・相場チェック → 店頭の値付け・仕入れ判断
  ↓
[昼] 窓口フェイズ（制限時間：営業時間 9:00〜18:00 を約 6〜8 分で）
     客が来る → 用件（質入れ/買取/請け出し/利払い/購入）
     → 書類照合・品物査定 → 金額提示・交渉 → 成立/拒否
  ↓
[夜] 帳簿フェイズ
     収支確認 → 生活費・家賃・借金返済 → 流質品の処分
     → 店舗/道具の投資 → ストーリーイベント
  ↓
[翌日へ]
```

## 6. Papers, Please との差別化

| | Papers, Please | 七つ屋 |
|---|---|---|
| 判断 | 入国の可否（二択） | **金額という連続値**＋可否 |
| 時間軸 | その日で完結 | **質札の期限**で数日後に結果が返ってくる（請け出し or 質流れ） |
| お金の使い道 | 家族の生活費 | 生活費＋**在庫・相場・投資**という経営判断 |
| 物の検査 | 書類のみ | 書類＋**品物そのもの**（ルーペ・天秤・ブラックライト等） |

特に「今日の判断が数日後に戻ってくる」質札システムを本作の核とする。
貸した客が返しに来るか、流れた品が高く売れるか――過去の自分の査定に答え合わせされる構造。

## 7. 勝利・敗北条件

- **目標**：30 日目の月末までに祖父の借金（例：¥3,000,000）を完済し、店を存続させる。
- **ゲームオーバー**
  - 手持ち資金が尽き、生活費を払えない日が 3 日続く
  - 警察の「違反点数」が上限に達し営業許可取消
  - 特定ルートでの破滅イベント（窃盗団との深入り 等）
- **マルチエンディング（例）**
  1. 老舗再興：借金完済・評判高
  2. 冷徹な金貸し：完済・評判低・良心低
  3. 町の灯：完済できないが住民に支えられ存続
  4. 裏の質屋：窃盗団と手を組む
  5. 営業停止 / 夜逃げ / 地上げされ閉店 など

## 8. 主要パラメータ

| パラメータ | 役割 |
|---|---|
| 資金 | 貸付・買取の原資。0 未満で貸付不可 |
| 借金残高 | 最終目標 |
| 評判 | 来客数・客層・交渉の柔軟さに影響 |
| 違反点数 | 警察の監視度。上限で営業停止 |
| 良心（隠しパラメータ） | エンディング分岐・一部イベント発生条件 |
| 鑑定眼（店主レベル） | 査定ヒントの精度、使える道具 |

## 9. アートとトーン

- ドット絵 or 減色イラスト。セピア・くすんだ緑・真鍮色を基調に、昭和の店先の空気感。
- 客の顔は大きく表示し、表情差分で心理を伝える（焦り・嘘・安堵）。
- BGM 控えめ。レジの音、天秤の音、時計の秒針で緊張感を出す。
- 重いテーマ（貧困・犯罪）を扱うが、ユーモアのある常連客で緩急をつける。

## 10. スコープ（MVP）

最初の縦切り（Vertical Slice）で作るのは：

- 7 日分のシナリオ、客 20 人程度、品目 15 種程度
- 道具 4 種（ルーペ・天秤・盗品リスト・身分証照合）
- 質入れ / 買取 / 請け出し / 店頭販売
- 規則追加 3 段階、違反点数、日次収支画面
