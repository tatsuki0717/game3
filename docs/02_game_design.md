# 02. ゲームデザイン詳細

> **実装版との差分**：週 1 回のオークションは「業者売却（いつでも即金・真価の 65%）」に、Day 20 の取引台帳ルールは「高額取引の在職証明確認」に置き換えた。店員の雇用・電子テスターの時短・ドラッグ&ドロップの机は未実装（カードは机上に並べて表示）。規則の解禁日は実装（`src/core/data/rules.ts`）が正。
>
> **追加実装**：効果音（WebAudio で合成、`src/ui/sound.ts`）、客の表情（平常/喜び/怒り/動揺/悲しみ/驚き。写真照合に使うパーツは変えず記号を重ねる）と機嫌ゲージ、取引結果の判子演出、所持金の増減表示、机上のカタログ控え、使用済み道具の表示と同じ検査・照合の重複防止、キーボード操作、夜の日報（返済進捗メーターと所持金・借金の推移グラフ）。夜の画面はスクロールなしの 1 画面で、左のコマンドメニュー（概況・帳簿と支払い・在庫・仕入れと広告・質札・借金と利率（信用金庫を含む）・投資と店員の 7 タブ、1〜7 キー）で切り替える。最初に開く「概況」は今夜の要点と純資産をカードにまとめ、要対応の項目を色とタブのバッジで知らせ、押すとそのタブへ移る。帳簿・在庫・質札はページ送り（← →）、在庫はアイテム欄のマス目と選んだ品の詳細欄。
>
> **経営要素の追加**：夜に「業者の仕入れ」（相場と卸値を見て在庫を買い、店頭で売る。テスター・UV が無いと動作不良・修理痕を見落とす）、「明日の広告」（町内チラシ：来客 +3 / 高価買取チラシ：来客 +2・持ち込みの約半分を指定品目に / 店頭セール：翌朝の店頭販売率 ×1.35）、「店員」（日給 ¥4,000。満期の請け出し・利払いを開店前に代行、偽の名義人を 40% で見逃す）、「信用金庫」（枠 ¥50,000＋評判×¥3,000、日利 1%。30 日目の夜に残っていれば先に取り立て、返せない分は借金に加算）を追加。日報に純資産の内訳、質札一覧に請け出し見込み（高/中/低）を表示する。

> **画面**：Web ページ風の縦スクロールをやめ、固定解像度のステージ（横 1280×720、縦持ちは幅 540 で高さを端末に合わせる）をウィンドウに合わせて拡大縮小する。ドットフォント（DotGothic16）と減色パレットで統一し、客の顔・証明写真はドット絵に変換、品目は 12×12 のドット絵アイコンで表示する（`src/ui/pixel.ts`）。

## 1. 画面構成（窓口フェイズ）

```
┌────────────────────────────────────────────┐
│ [時計 10:42]  [資金 ¥184,000]  [違反 ■■□□□]   │ ← HUD
├────────────────────────────────────────────┤
│                                            │
│        客の顔・セリフ吹き出し                 │ ← 店先エリア
│        （表情差分 / 後ろの待ち行列）          │
├───────────────────┬────────────────────────┤
│  作業机（ドラッグ可）  │ 道具トレイ               │
│  ・品物              │  ルーペ / 天秤 / UVライト │
│  ・身分証            │  磁石 / カタログ          │
│  ・質札・書類         │ 規則帳 / 盗品手配書        │
├───────────────────┴────────────────────────┤
│ [照合モード]  [金額入力 ¥_____]  [提示] [断る]  │ ← アクション
└────────────────────────────────────────────┘
```

- 品物・書類は机の上でドラッグして並べ、重ねて読める（Papers, Please 式）。
- **照合モード**：2 つの項目（例：身分証の写真 と 客の顔、品物の刻印 と カタログの刻印）をクリックすると、一致/不一致がハイライトされる。不一致を見つけると「指摘」できる。

## 2. 客の用件

| 用件 | 内容 | 店の判断 |
|---|---|---|
| 質入れ | 品物を担保にお金を借りたい | 貸付額・可否を決める。質札を発行 |
| 買取 | 品物を売りたい | 買取額・可否を決める。即在庫化 |
| 請け出し | 元金＋利息を払って品物を返してほしい | 質札・本人確認。名義人本人の請け出しは断れない（名義違いは断る）。品物を返却 |
| 利払い | 利息だけ払って期限延長。たまに利息の減額を頼みに本人が窓口へ直接来る | 質札確認。減額に応じるか、元の利息で払ってもらうかを選ぶ（店員は代行しない） |
| 購入 | 店頭品を買いたい | 値引き交渉に応じるか |
| 特殊 | 刑事の聞き込み、窃盗団の取引持ちかけ、地上げ屋 等 | ストーリー分岐 |

## 3. 査定システム

### 3.1 品物の隠しパラメータ

各品物は以下の **真の状態** を持ち、プレイヤーは道具を使って推測する。

| 隠しパラメータ | 例 | 見抜く手段 |
|---|---|---|
| 真贋（本物/偽物） | ブランド時計のコピー品 | ルーペで刻印、天秤で重量、カタログと比較 |
| 状態ランク S〜D | 傷・動作不良 | ルーペ、動作確認ボタン |
| 素材 | 金 18K か金メッキか | 磁石、試金石、天秤（比重） |
| 盗品フラグ | 盗難届が出ている | 盗品手配書のシリアル番号と照合 |
| 市場価値 | 相場で変動 | カタログ（基準価格）×ニュース（相場係数） |

### 3.2 道具

| 道具 | 効果 | 入手 |
|---|---|---|
| ルーペ | 品物の拡大表示。刻印・傷・シリアルが読める | 初期 |
| 天秤 | 重量を表示。カタログ値と比較 | 初期 |
| 盗品手配書 | 警察から毎朝届くシリアル・特徴リスト | 初期（毎日更新） |
| 品目カタログ | 基準価格・正規刻印・重量 | 初期（ページ追加で拡張） |
| 磁石 | 貴金属かどうか（くっつけば偽物） | Day 3 購入可 |
| UV ライト | 偽造身分証の透かし・修復痕を発見 | Day 6 購入可 |
| 試金石セット | 金の純度判定 | Day 10 購入可 |
| 電子テスター | 家電の動作確認を時短 | 投資 |

道具は **使うと時間が経過する**。全部の検査をすると客をさばけない――このトレードオフが Papers, Please 的な時間圧になる。

### 3.3 査定額の目安

```
推定価値 = カタログ基準価格 × 状態係数 × 相場係数
推奨貸付額 = 推定価値 × 0.5〜0.7   （質入れ）
推奨買取額 = 推定価値 × 0.3〜0.5   （買取）
```

ゲームは推奨値を直接は表示しない。鑑定眼レベルが上がると「目安レンジ」が表示されるようになる。

## 4. 交渉システム

- 客ごとに **希望額** と **最低許容額**（隠し）と **性格**（強気/弱気/嘘つき/常連）がある。
- プレイヤーが金額を提示 → 客が「受諾 / 反論して希望額を言い直す / 怒って帰る」で反応。
- 交渉回数の上限は 3 回程度。回数を重ねるほど時間を消費し、客の機嫌ゲージが下がる。
- **指摘カード**：照合モードで見つけた欠陥（「ベゼルに傷がある」「重量が足りない」）を交渉中に突きつけると、客の希望額が下がる。嘘の指摘はできない（Papers, Please の「不一致指摘」と同じ手触り）。
- 困窮した客にあえて高く貸す → 良心＋、評判＋、利益－。

## 5. 規則（コンプライアンス）システム

日を追うごとに規則帳にルールが追加される。違反すると翌朝「指導票」が届き、罰金＋違反点数。

| 解禁日 | 規則例 |
|---|---|
| Day 1 | 取引には身分証の提示が必須。期限切れは不可 |
| Day 2 | 盗品手配書に載っている品は受け取らず、通報する |
| Day 4 | 18 歳未満とは取引禁止（生年月日を確認） |
| Day 6 | 身分証の住所が潮見市外の客は、¥50,000 超の取引に 2 点目の書類が必要 |
| Day 9 | 刃物・銃刀類は受け付けない |
| Day 12 | 法定上限金利の改定（利率設定 UI の上限が変わる） |
| Day 15 | 同一人物の同日 2 回目の取引は禁止（行列に同じ客が変装して並ぶ） |
| Day 20〜 | 取引台帳への記入（品名・特徴・客名）を義務化。書き間違いも違反 |

- 規則はデータ駆動（後述の Rule 定義）で、組み合わせて難度を上げる。
- **あえて違反する選択** もできる（例：期限切れ身分証の老人に貸す）。発覚確率は評判と刑事の監視度で決まる。

## 6. 質札（ローン）システム

- 質入れ成立時に **質札** を発行：元金、利率、期限（ゲーム内 3〜7 日）、品物 ID、客 ID。
- 期限日に客は下記いずれかの行動を取る（客の経済状況＋性格＋ストーリーで確率決定）：
  - 請け出し（元金＋利息を回収）
  - 利払いして延長
  - 来ない → **質流れ**：品物の所有権が店に移り、販売可能になる
- 高く貸しすぎると「わざと流す」客が増え、損をする。安すぎると客が来なくなる。
- 質札は夜フェイズの **帳簿** で一覧でき、満期予定日カレンダーを確認できる。

## 7. 経営フェイズ（夜）

### 7.1 収支画面
- 当日の 貸付 / 回収 / 利息収入 / 買取 / 販売 / 罰金 を一覧（Papers, Please の家計画面風）。
- 支出項目：家賃、光熱費、生活費（食費・暖房・家族の薬代）、借金の日割り返済。払わない項目を選べるが、家族の状態が悪化する。

### 7.2 在庫と販売
- 在庫（質流れ品・買取品）を以下の方法で処分：
  - **店頭陳列**：値札をつける。翌日の来客がランダムに購入。陳列枠には上限（投資で拡張）。
  - **業者オークション**：週 1 回（7 日ごと）。相場で即現金化、ただし手数料。
  - **持ち越し**：相場上昇を待つ。保管枠を圧迫。
- 相場ニュース（例：「金価格高騰」「ゲーム機ブーム到来」「偽ブランド大量流入」）で品目カテゴリごとの相場係数が変動する。

### 7.3 投資
| 項目 | 効果 |
|---|---|
| 道具購入 | 検査手段の追加 |
| ショーケース拡張 | 陳列枠＋ |
| 防犯設備 | 強盗イベントの被害軽減 |
| 看板改装 | 来客数＋、客層変化 |
| 店員を雇う | 請け出し・利払いなど単純な用件を自動処理 |
| 金庫拡張 | 保管枠＋ |

## 8. 客とストーリー

### 8.1 客の種類
- **ランダム客**：テンプレート＋パラメータ生成（名前・顔パーツ・所持品・用件・性格・経済状況）。
- **ストーリー客**：固定日に登場する名前付きキャラクター。複数日にまたがる。

### 8.2 主なストーリーライン（例）
| キャラ | 概要 |
|---|---|
| 母子家庭の早苗 | 子供の学費のため、毎週少しずつ指輪や着物を質入れに来る。最後に請け出せるかはプレイヤー次第 |
| 刑事・黒田 | 窃盗団を追う。協力すると違反点数の免除、裏切ると…… |
| 窃盗団の「タカ」 | 盗品を高く買えと持ちかける。断り続けると店に嫌がらせ |
| 地上げ屋・不動産会社 | 店の買収を迫る。借金を肩代わりする代わりに店を手放す取引 |
| 祖父の古い常連 | 祖父の過去と、店の金庫に眠る「ある品物」の謎 |

### 8.3 イベント条件
ストーリーイベントは `日付` `フラグ` `パラメータ閾値` の組み合わせで発火する（データ駆動）。

## 10. バランス値（実装版）

自動プレイ（`npm run simulate`）で調整した現在の値。定数は `src/core/config.ts` に集約している。

| 項目 | 値 |
|---|---|
| 初期資金 | ¥300,000 |
| 借金 | ¥1,000,000（7/14/21/28 日目の夜に ¥50,000 / ¥100,000 / ¥150,000 / ¥200,000 の定期返済、残りは 30 日目の夜） |
| 定期返済を払えない | 即座に差し押さえ（ゲームオーバー） |
| 日次固定費 | 家賃 ¥5,000（必須）/ 食費 ¥3,000 / 暖房費 ¥2,500（11 日目〜）/ 祖母の薬代 ¥8,000（病気時） |
| 質札 | 期限 5 日、利率 10%（夜に 3〜15% で変更可、12 日目から上限 9%） |
| 違反点数上限 | 10 点で営業許可取消（7 日ごとに 1 点回復） |
| 陳列枠 | 6（ショーケース増設で +4） |
| 業者売却 | 真の価値の 65%（偽物はほぼ 0） |
| 通報の謝礼 | ¥10,000 |
| 業者の仕入れ | 1 晩 3 点（評判 70 以上で 4 点）、卸値は見えている価値の 55〜80% |
| 広告 | 町内チラシ ¥6,000 / 高価買取チラシ ¥8,000 / 店頭セール ¥5,000 |
| 店員 | 日給 ¥4,000 |
| 信用金庫 | 枠 ¥50,000＋評判×¥3,000、日利 1% |
| 営業時間 | 9:00〜18:00（実時間 0.8 秒でゲーム内 1 分。道具・交渉でも時間が進む） |

バランスの目安：慎重に検査して交渉するボットで完済率はおよそ 6 割、希望額で即決するボットは 1 週目で破綻する。仕入れ・広告・店員・融資を機械的に使う manager ボットは差し押さえにならず平均残債も半分ほどになるが、経費がかさむぶん完済率は約 5 割に留まる（使い方次第の要素）。
